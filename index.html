Ariadne

The thread out of the cloud-storage labyrinth

Ariadne is a personal tool that keeps one person's Google Drive in order. It runs on its owner's own computer, maps every folder into ten named rooms, finds duplicates and clutter, and moves files only after the owner approves a plan.

It is not a public service: there is no sign-up, no server and no other users. The Google sign-in exists only so the owner's own computer can organize the owner's own Drive.
